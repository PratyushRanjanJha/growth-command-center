# Growth Command Center: Challenge A (Attendee Growth)

React 18 + Tailwind 3 + Recharts 2, built with Vite into one self-contained HTML file.

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/index.html (single file, open directly in a browser)
```

## Files
- `src/histData.js`: exact aggregates from `Attendee_Dataset.xlsx`. Duplicate IDs are removed, and attendance counts only external people with an admitted + verified check-in. Generated by `scripts/gen.py`; to rebuild it, run `python3 scripts/gen.py Attendee_Dataset.xlsx src/histData.js`.
- `src/model.js`: Part 1 targets (base 3,000 / stretch 5,000), the five bets, scale/change/stop thresholds, CAC guardrail, alert rules R1–R3, the metric engine and CSV export.
- `src/copilot.js`: builds the live JSON context and system prompt, calls the Anthropic API or the built-in Claude, parses proposed tasks, and runs the deterministic fallback engine.
- `src/App.jsx`: the UI (dashboard, diagnostic engine, campaign editor + task tracker, Copilot pane).

## Copilot providers
1. **Anthropic API key:** a browser-direct call to `api.anthropic.com`. It works when you run the app locally. The hosted claude.ai page blocks outside requests, so there the app falls back automatically. The key is kept in memory only and is never saved.
2. **Claude built-in:** available when the page is hosted on claude.ai (the `sample` capability).
3. **Deterministic engine:** offline rules over the same live state. It handles funnel diagnosis, budget reallocation, task creation, CAC, capacity, per-campaign questions, and out-of-scope questions.

App state (mode, simulation values, tasks, chat) is saved to localStorage under the key `gcc-attendee-v1`.
